# 마이링크 (My Link) - 사용자 시나리오 (User Scenario)

본 문서는 **마이링크**의 주요 타겟 사용자인 개발자와 크리에이터가 서비스를 이용하는 전형적인 흐름을 정의합니다.

---

## 1. 시나리오 A: 주니어 개발자 '김철수' (브랜딩 및 구직용)

### 1.1. 페르소나
- **목표**: 자신의 기술적 역량을 한 페이지에 정리하여 이력서나 SNS 프로필에 한 줄 링크로 공유하고 싶음.
- **주요 링크**: GitHub, 기술 블로그(Tistory), 노션 포트폴리오, LinkedIn.

### 1.2. 서비스 이용 흐름
1. **가입 및 로그인**: 구글 계정으로 간편하게 가입함.
2. **프로필 설정**: 자신의 개발자 캐릭터 이미지와 함께 "성장하는 프론트엔드 개발자"라는 바이오를 작성함.
3. **링크 등록**:
    - GitHub URL을 입력함. 시스템이 자동으로 GitHub 파비콘을 불러와 아이콘으로 설정함.
    - 기술 블로그와 노션 링크를 추가함.
4. **콘텐츠 임베드**: 개발자 모드 옵션을 선택하여 자신의 **GitHub 잔디(Contributions)** 그래프를 상단에 노출함.
5. **공유**: 생성된 `mylink.com/@chulsoo` 링크를 자신의 인스타그램 프로필과 이력서 이메일 하단에 추가함.

---

## 2. 시나리오 B: 테크 크리에이터 '이영희' (콘텐츠 홍보용)

### 2.1. 페르소나
- **목표**: 유튜브 채널의 신규 영상 조회수를 높이고, 팔로워들에게 다른 SNS 채널을 효과적으로 안내함.
- **주요 링크**: 유튜브 최신 영상, 유료 강의 페이지, 인스타그램, 틱톡.

### 2.2. 서비스 이용 흐름
1. **로그인**: 기존 구글 계정으로 접속함.
2. **미디어 임베드**: 유튜브 최신 영상 URL을 임베드 섹션에 입력함. 페이지 상단에 영상이 플레이어 형태로 바로 노출됨.
3. **링크 관리**: 
    - 새로 오픈한 온라인 강의 링크를 추가함. (해당 사이트의 파비콘이 아이콘으로 자동 적용됨)
    - 이제는 사용하지 않는 예전 이벤트 링크를 리스트에서 삭제함.
4. **디자인 확인**: **shadcn/ui** 기반의 깔끔한 테마가 적용된 페이지를 실시간 미리보기로 확인하며 즐거워함.
5. **확산**: 관리자 화면에서 자신의 페이지로 연결되는 **QR 코드**를 다운로드하여 영상 인트로 화면에 삽입함.

## 3. 핵심 사용자 여정 (User Journey Table)

| 단계 | 사용자 행동 | 시스템 반응 |
| :--- | :--- | :--- |
| **인증** | 구글 로그인 버튼 클릭 | Firebase Auth를 통해 인증 후 대시보드 진입 |
| **편집** | 링크 추가 (URL 입력) | URL에서 파비콘 추출 및 아이콘 자동 설정 |
| **특화 기능** | 임베드 코드/URL 입력 | GitHub 잔디 또는 유튜브 플레이어 렌더링 |
| **공개** | 고유 URL 배포 | 반응형 최적화된 랜딩 페이지 노출 |
