# 마이링크 (My Link) - 서비스 기능 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트 명**: 마이링크 (My Link)
- **목적**: 개발자와 크리에이터를 위한 통합 링크 서비스로, 단순한 링크 나열을 넘어 개인의 포트폴리오와 브랜딩 정체성을 효과적으로 드러낼 수 있는 랜딩 페이지를 제공함.
- **대상 사용자**: 
    - **개발자**: 자신의 GitHub, 기술 스택, 블로그, 포트폴리오를 정리하고 싶은 유저.
    - **크리에이터**: SNS 채널, 작업물 유튜브/스포티파이 콘텐츠를 공유하고 싶은 유저.

## 3. 기능 상세 설명

### 3.1. 인증 및 보안 (Firebase 기반)
- 사용자의 편의성을 위해 **구글 소셜 로그인**으로 인증 과정을 단일화함.
- Firebase의 실시간 데이터베이스(Firestore)를 활용하여 사용자 링크 데이터를 관리.

### 3.2. 링크 시스템 (Link System)
- **자동 파비콘 설정**: 유저가 URL을 입력하면 해당 사이트의 **파비콘(Favicon)**을 자동으로 추출하여 아이콘으로 표시함.
- **심플한 관리**: 드래그 앤 드롭이나 활성화/비활성화 등의 복잡한 기능 없이, 리스트를 추가/삭제하는 직관적인 방식 유지.
- **실시간 미리보기**: 대시보드 편집기에서 수정 사항을 실시간으로 확인 가능.

### 3.3. 개발자/크리에이터 특화 기능
- **개발자 모드**: GitHub Contributions(잔디) 그래프 임베드 및 주요 기술 스택 뱃지 노출 지원.
- **크리에이터 모드**: 유튜브 영상 또는 스포티파이 플레이리스트 임베드를 통한 콘텐츠 직접 노출.

### 3.4. 디자인 시스템 (shadcn/ui 활용)
- **일관된 UX**: shadcn/ui를 활용하여 깔끔하고 세련된 UI 컴포넌트 제공.
- **테마 최적화**: 개발자와 크리에이터에게 어울리는 현대적이고 미니멀한 테마 적용.

### 3.5. (차별화) 방문자 통계 (Roadmap)
- 링크별 클릭률(CTR) 및 기간별 유입 등 인사이트 데이터 제공 (추후 구현).

---

## 4. 제안 및 참고사항

> [!NOTE]
> - **파비콘 추출 방식**: 유료 API보다는 Google Favicon Service나 기타 무료 오픈 서비스를 활용하여 효율적으로 구현하는 것을 제안합니다.
> - **순서 및 활성화 제외**: 복잡성을 줄이고 MVP(Minimum Viable Product) 본연의 기능인 '빠른 링크 공유'에 집중하는 방향으로 조정되었습니다.
